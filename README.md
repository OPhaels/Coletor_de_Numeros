<h1>🔢 Coletor de Números</h1>

<p>Programa simples com interface gráfica desenvolvido para suprir uma necessidade: remover números de imagens e transferí-los para um campo de texto que possa ser copiado, ignorando as letras. Não armazena informações, apenas serve para a coleta de números das imagens. As cores da imagem são removidas e com a ajuda dos filtros conseguimos identificar números.</p>

<h2>Como Usar ? </h2>

<p>Siga os passos abaixo para utilizar o programa:</p>

<ol>
  <li>Vá em <code>&lt;&gt; CODE</code></li>
  <li>Clique em <code>Download ZIP</code></li>
  <li>Depois do download, basta extrair a pasta <code>coletor_de_numeros-main.zip</code></li>
  <li>Siga esse caminho: <code>Coletor_de_Numeros-main\dist\coletor</code></li>
  <li>Por último, inicie o <code>coletor.exe</code></li>
</ol>

<h2>Funcionalidades</h2>

<ul>
  <li>Extração automática de números de imagens</li>
  <li>Remoção de cores para melhor identificação</li>
  <li>Filtros otimizados para detecção numérica</li>
  <li>Interface intuitiva e fácil de usar</li>
  <li>Campo de texto editável com números extraídos</li>
  <li>Não armazena dados do usuário</li>
</ul>
